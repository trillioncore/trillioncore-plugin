# Trillioncore

Find authorized organizations and connected data, search and read records, query approved tables, and prepare evidence-backed briefings. Create or update native documents and perform provider actions only when explicitly authorized. Connect your Trillioncore account through the existing hosted MCP service; no local CLI installation is required.

An installable connection to the existing Trillioncore hosted MCP service. No local Trillioncore CLI,
new server, or duplicate implementation is required. Each user authorizes their
own organizations, accounts, and optional write operations in Trillioncore's browser flow.
